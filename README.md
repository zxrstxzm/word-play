# 🐰 兔兔小剧场（rabbit-theater）

SillyTavern 扩展：在输入菜单中注入一个独立面板，根据当前角色、用户人设、世界书和聊天记录生成外置小剧场（番外），支持面板预览或嵌入到最新 AI 回复楼层。

## 功能

- 剧本库：分类管理、批量操作、导入导出
- 从对话补全预设 / 世界书批量导入为剧本、破限、文风
- 生成上下文：角色描述、用户人设、世界书条目、历史聊天记录
- 主 API 或副 API 生成，副 API 预设管理
- 自动生成：收到新 AI 回复后自动出小剧场
- 输出：面板预览、嵌入楼层、全屏查看、收藏、导出 TXT / 书摘图片
- 界面主题与自定义 CSS
- 渲染正则 / 渲染 CSS：仅作用于小剧场显示
- 历史聊天记录只读标签 / 排除标签

## 安装

在 SillyTavern「扩展 → 安装扩展」中填入本仓库地址，或将本文件夹放入 `public/scripts/extensions/third-party/`。

## 使用说明

### 渲染正则 / CSS

- 导入页类型选「预设绑定正则（渲染用）」，选择对话补全预设后勾选正则导入。
- 导入目标选「导入为渲染 CSS」，可把预设或世界书条目中的 CSS（含 `<style>` 时只取其内容）导入。
- 设置页「小剧场渲染（正则 / CSS）」中可总开关、逐条开关、删除，或手动添加 CSS。
- 只影响显示（面板预览、嵌入楼层、全屏、收藏）；源码、导出和发给 AI 的内容保持原样。

### 历史聊天记录标签

勾选「读取历史聊天记录」后可设置：

- 排除标签：删除这些标签及其内容，例如 `thinking, status`
- 只读标签：只读取这些标签内的内容，例如 `content, 正文`

多个标签用逗号分隔，不用写尖括号。先排除再只读；设置只读标签后，没有这些标签的 AI 消息会跳过，用户消息保留原文。
